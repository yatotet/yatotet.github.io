Pasang Sistem e-Muster Chit Sebagai Aplikasi (App)

Boleh dipasang terus di skrin utama telefon (Android/iOS), PC, atau dijadikan fail APK

Pelayar anda menyokong pemasangan terus!
Klik butang di sebelah untuk memasang ikon aplikasi e-Muster Chit terus ke peranti anda.
1. Telefon (Android & iPhone)

Pasang Terus dari Pelayar (PWA)

  1. Muat naik fail index.html ke GitHub Pages anda (yatotet.github.io).
  2. Buka https://yatotet.github.io di telefon menggunakan Chrome (Android) atau Safari (iPhone).
  3. Tekan menu ⋮ (3 titik) di Chrome dan pilih "Install app" / "Add to Home screen" (atau tekan Share ➔ Add to Home Screen di iPhone).
  4. Ikon e-Muster FGV akan muncul di skrin telefon seperti aplikasi sebenar (skrin penuh tanpa bar URL)!
2. Fail .APK Android

Tukar Jadi Fail Pemasang (.APK)

  1. Selepas laman https://yatotet.github.io aktif, buka laman percuma PWABuilder.com atau WebIntoApp.com.
  2. Masukkan URL https://yatotet.github.io atau muat naik fail index.html anda.
  3. Klik Package for Store / Generate APK untuk memuat turun fail .apk yang boleh dikongsi terus melalui WhatsApp.
3. Komputer / Laptop (PC)

Aplikasi Desktop Windows / Mac

  1. Buka pautan aplikasi di pelayar Google Chrome atau Microsoft Edge.
  2. Klik ikon Pasang (komputer dengan anak panah) di sebelah kanan bar alamat URL.
  3. Aplikasi akan dipasang terus ke Desktop & Taskbar dan boleh dibuka walaupun tanpa internet (luar talian).
Sedia untuk dimuat naik: Aplikasi ini telah dilengkapi konfigurasi Web App Manifest dan ikon aplikasi rasmi.
